ESTA CÓPIA NÃO PRECISA DE INTERNET, GITHUB OU FIREBASE PARA FUNCIONAR.

COMO INSTALAR NO COMPUTADOR (WINDOWS)
1. Receba o arquivo ZIP pelo WhatsApp ou baixe a cópia offline.
2. Clique com o botão direito no ZIP > Extrair Tudo.
3. Mantenha TODOS os arquivos e a pasta "assets" juntos.
4. Abra a pasta extraída e clique duas vezes em "index.html".
5. O painel abrirá no navegador (Chrome ou Edge).
6. Para deixar fixo na área de trabalho: botão direito em "index.html"
   > Mostrar mais opções > Enviar para > Área de trabalho (criar atalho).
   Você pode renomear o atalho para "Painel PM / SD".

NÃO ABRA O INDEX.HTML DIRETAMENTE DENTRO DO ZIP.
Extraia a pasta primeiro para que estilos, scripts e logos sejam carregados.

USO SEM INTERNET
- Não é preciso entrar com e-mail ou senha do Firebase.
- Quem tiver esta cópia poderá editar os dados do próprio computador.
- Editor de Dados, Justificativas, Docas, Dashboard e Fechamento usam informações locais.
- Nenhuma alteração é enviada automaticamente para outros computadores.
- Para atualizar dados operacionais, use o Editor de Dados e cole Extração/Base.
- O histórico local só contém dados criados ou importados neste computador.
- PDFs podem ser impressos pelo navegador; a captura de imagem usa biblioteca local.

SALVAR E LEVAR DADOS PARA OUTRO COMPUTADOR
- Clique em "Salvar backup": será baixado um arquivo JSON.
- Guarde o JSON junto aos seus documentos.
- Para recuperar ou transferir os dados, clique em "Abrir backup" e selecione o JSON.
- Atenção: restaurar um backup substitui os dados atuais daquele computador.
- O navegador também pode guardar dados localmente, mas eles podem sumir se o
  usuário limpar os dados de navegação, mudar de navegador ou mover o arquivo.
  Por isso, faça BACKUP regularmente.

ARQUIVOS PRINCIPAIS
- index.html: clique duas vezes para abrir o painel.
- offline-utilities.css: estilos e ícones disponíveis sem internet.
- overview-reference-pm-sd.css: estilos complementares locais.
- html2canvas.min.js: captura de imagens sem CDN.
- ondas-pm-sameday-dados.js: configuração e dados iniciais.
- assets/: logos utilizados no painel.

IMPORTANTE
- Esta é uma CÓPIA estática e independente do painel online PM/SD.
- Novas atualizações do projeto online NÃO aparecem automaticamente aqui.
- O painel não busca novos dados do Mercado Livre ou do Firebase sozinho.
- Arquivos gerados pelo painel ficam salvos no próprio computador.
- Para compartilhar os dados atualizados com outra pessoa, envie o backup JSON.

Se o navegador bloquear armazenamento local, use "Salvar backup" antes de fechar
e "Abrir backup" quando reabrir o painel.
